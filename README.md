### The Research Method
- Question a topic — spot a gap or tension worth studying
- Form a hypothesis — an educated guess at the answer
- Design a method — plan how to test it
- Carry it out — run the plan & record what happens
- Analyze the data — see what it actually shows
- Draw conclusions — state what you've learned
